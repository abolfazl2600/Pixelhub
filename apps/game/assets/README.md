# Asset provenance

- `levels/sunflower.json` (preserved V1 fixture): original 16 × 16 pixel fixture created for Pixelhub V1; licensed under the repository Apache-2.0 license. No competitor artwork or user photos.
- `fonts/Vazirmatn.ttf`: Vazirmatn by Saber Rastikerdar, distributed under the SIL Open Font License 1.1. Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/vazirmatn). The unmodified font and its license are bundled locally; no runtime font service.
- `fonts/Roboto.ttf`: Flutter Web's engine fallback font, bundled to avoid remote font requests. Unmodified Google Fonts Roboto, SIL OFL 1.1; see `fonts/Roboto-OFL.txt`.
- Web and Android launcher icons: owner-selected neon purple paintbrush painting a rainbow of pixel tiles (2026-10-21), replacing the earlier blue easel illustration. The checked-in square PNG source is `brand/pixelhub_mark.png` (optimized 128 × 128 launcher source); `apps/game/tool/generate_launcher_icons.dart` regenerates the required Android mipmap, Web manifest, favicon and 512 × 512 Play listing sizes during Android and Web builds. Source art is AI-generated and owner-selected. Verify distribution rights and visually review the generated store listing icon before publication.

V1 fixtures carry `schemaVersion` and `contentVersion`. A production level checksum and migrations are part of the V2 contract; V1 has no saved sessions.

V2 uses ten original geometric fixtures listed in `levels/catalog.json`, including `sunflower-v2.json` with a new content version. All are repository Apache-2.0 assets. Schema 2 SHA-256 canonical payload is defined in ADR 0002; existing versioned assets must remain immutable once published. No competitor art or generated-AI artwork is used.

V3 expands the catalog to 40 pictures with 30 additional original geometric designs created for Pixelhub on 2026-10-12. The construction source is `tool/generate_catalog.py` (ellipses, polygons and lines); these assets use the repository Apache-2.0 license. `metadata.json` records nature/animals/objects/patterns/space categories and tags. Existing V2 level files are preserved. Artistic/device QA remains pending; the optional roadmap target of 80–120 is not claimed.

On 2026-10-17 the bundled offline catalog gained nine additional original geometric/pixel interpretations, without modifying or replacing existing level IDs: four public-domain masterworks (Mona Lisa, The Starry Night, The Great Wave, Girl with a Pearl Earring), four Iranian architectural subjects (Azadi Tower, Persepolis, Si-o-se-pol, Nasir al-Mulk Mosque) and an original eight-point Shamsa ornament. Each is a self-contained checksummed schema-v2 JSON file in `levels/offline-*.json`, with Persian and English titles, and is bundled directly into Android/Web assets for use without downloading online level packs. The masterworks are new pixel drawings inspired by historic public-domain artworks, not copied competitor assets. The geometric architecture designs and Shamsa were drawn from basic shapes for this project. The original 40 level files and animation pack remain unchanged; the catalog now contains 49 bundled levels. `tool/generate_catalog.py` preserves the newly published immutable offline files during future baseline regeneration. Visual QA and build validation have not been run in this development session.

On 2026-10-18, four approved generated pixel-art references (Nasir al-Mulk Mosque, Snowy Penguin, Gentle Elephant and Colorful Parrot) were quantized into playable cell grids. The bundled mosque uses `levels/offline-nasir-molk-v2.json` with the stable `offline-nasir-molk` ID and content version 2; the original v1 file remains unchanged. The three online animal replacements are reproducibly packaged by `tool/online_animal_redesigns_pack.py` under fresh IDs, while their previous IDs are retired from the current public catalog and historical Release assets remain immutable. The source PNGs are not bundled, keeping them out of APK/Web asset payloads. This artwork is generated-reference-derived rather than a hand-authored geometric fixture; verify provenance and distribution rights before external distribution. CI, build and visual QA have not been run in this development session.

Imported personal pictures are private local user content, excluded from repository assets and public offline caches. Only their converted grids are persisted; they inherit no public-content license from this catalog.
