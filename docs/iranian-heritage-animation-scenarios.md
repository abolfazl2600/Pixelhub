# Iranian heritage artwork and animation scenarios

This collection adds 23 immutable online coloring levels. Each animation is an
optional checksum-bound companion; it never modifies the base artwork or saved
painting progress. The published loop uses 12 frames at 150 ms per frame (1.8 s)
and returns to the original pixels in the first and last frame. Motion is
palette-only and intentionally subtle. The current renderer caps a sidecar at
60 frames; these scenarios use 12-frame loops, and can be refined with more
frames in a future compatible schema update.

## Implementation and release behavior

- New IDs are unique, use `levelVersion: 1`, and never replace prior releases.
- The pack generator emits bilingual schema-v2 level JSON and PNG previews.
- The Pages workflow assembles the immutable Release catalog first, then derives
  per-picture animation checksums from the exact published levels, validates
  sidecars, and publishes the animation catalog metadata alongside the static
  fallback.
- Each animation uses a stable level ID as its parent; the animation sidecar is
  additive and does not affect the painting checksum, downloaded copy, or
  offline progress.
- The scene art is original pixel-art interpretation. The named monuments are
  simplified and should receive reference-based visual review before being
  described as historically exact.
