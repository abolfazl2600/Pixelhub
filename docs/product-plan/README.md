# Pixelhub | سند مادر برنامه توسعه

> وضعیت: برنامه‌ریزی / مستندات (این پوشه هنوز سورس‌کد اجراشدنی نیست)  
> تاریخ آغاز مستندات: 2026-10-12  
> هدف: بازی رنگ‌آمیزی شماره‌ای / پیکسل‌آرت با تمرکز Android و نسخه Web با **همان UI موبایل**.

## اصل‌های تغییرناپذیر
1. یک پروژه Flutter و یک موتور بازی مشترک برای Android و Web؛ در دسکتاپ وب همان قاب موبایل به‌صورت وسط‌چین نمایش داده شود، **نه طرح Responsive دسکتاپ**.
2. ساخت، تست و انتشار از طریق GitHub Actions؛ کاربر به نصب Flutter/Android Studio روی رایانه شخصی نیاز نداشته باشد.
3. GitHub Pages فقط میزبان فایل‌های استاتیک نسخه Web است؛ Backend، دیتابیس و پرداخت آنلاین در سرویس مستقل اجرا می‌شوند.
4. Local-first، اجرای آفلاین محتوای دانلودشده، ذخیره پیشرفت با نسخه‌بندی محتوا و امکان Sync در مراحل بعدی.
5. تفکیک «قابلیت مستندشده»، «پیاده‌سازی‌شده»، «تست‌شده» و «منتشرشده». تا قبل از CI موفق، ادعای قابل اجرا بودن نداریم.
6. نام، برند، تصاویر و سورس اختصاصی رقبا کپی نمی‌شوند. هر تصویر باید منشأ/مجوز مشخص داشته باشد.

## قواعد پایان هر نسخه (Definition of Done)
- تمام «داخل محدوده»های همان نسخه با معیار پذیرش مندرج در پرونده نسخه پاس شوند.
- نسخه‌های Android و Web از **یک commit** ساخته شوند و نتایج CI ثبت شود.
- تست‌های خودکار مرتبط، مرور دستی روی گوشی واقعی و مرورگر، و بررسی حفظ پیشرفت پاس شوند.
- قابلیت ناقص یا خطرناک با Feature Flag خاموش بماند یا از نسخه حذف شود.
- Change Log، ریسک‌های باقیمانده و تصمیم‌های فنی به‌روزرسانی شوند.
- تحویل نسخه بعد فقط پس از عبور از gate نسخه قبلی انجام شود.
